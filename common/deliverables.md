# 项目成果说明

只完成所选项目。另一项目可以保持基线状态，无需运行或修改。

个人仓库应保留：

- 源码、测试、项目清单、锁文件与必要配置。
- 所选项目的 README：环境、启动方式、检查方法、已完成能力、已知问题。
- 自然的 Git 提交历史，以及起始代码来源。
- 简短学习记录，例如 PROGRESS.md，说明遇到的问题、假设、验证结果和下一步；不要求日报。

请明确区分基线已有功能和个人新增修改。不要为了显示完成度而将基线功能写成自己实现，也不要隐藏仍失败的检查。

允许阅读资料、搜索、使用 AI、讨论和求助；需理解并验证最终采用的代码。对外部代码或关键建议记录来源与自己的处理，不能将代做或复制冒充原创。

未完成全部层级、检查尚有问题时，如实说明现状和定位过程。已有正常功能需保持可运行，新增功能需要自己的测试。公开自查只是少量样例，不等于完成全部验收要求。

CI 是可选扩展：可自行研究在干净环境中执行所选项目的检查。本仓库不提供可直接复制的完整 workflow。
