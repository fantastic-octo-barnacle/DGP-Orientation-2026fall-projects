# 项目成果说明

客户端和最终选择的服务端层级都属于项目成果。客户端与异步服务端是必做内容；同步服务端可以作为中间层完成，也可以在确认自己能直接开始异步实现后跳过。保留 Git 提交历史，不要只提交一个无法说明过程的最终快照。

为每个完成的层级提供清楚的说明，让读者了解项目功能、运行方式、使用入口与参数、通信接口，以及如何运行测试。配上必要的使用示例，说明已知问题。文档结构自行组织，接口说明可引用仓库已有协议，并注明已实现的功能和自行扩展的接口。

按层级要求实现功能、编写测试，并对照[统一验收清单](acceptance.md)验证。若跳过同步服务端，请在成果说明中写明原因和实际完成的层级。

鼓励查阅资料、使用 AI，需理解并验证采用的代码。
