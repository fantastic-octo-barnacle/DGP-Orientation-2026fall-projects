# RM 软件组个人项目

这里提供共通学习指引、两个可选项目的任务书、可运行的起始代码及验证材料。你需要完成共通基础学习，然后选择 **一个** 编程项目，在已有代码上继续开发。

项目关注你如何阅读、学习、定位问题和验证修改。已有基线不是你的新增成果；完成所有层级也不是唯一目标。保留真实的代码变化、测试、说明及未解决的问题。

## 从哪里开始

1. 点击 GitHub 的 **Use this template → Create a new repository**，创建自己的仓库；不要向本仓库直接提交个人答案。
2. 阅读 [Git/GitHub](common/git-github.md) 与 [WSL2](common/wsl2.md) 指引。已掌握的练习可跳过；WSL2 安装只适用于条件允许的 Windows 设备。
3. 选择一个项目，阅读它的 README 和协议，恢复环境，先运行基线与已有检查。
4. 按阶段实现、测试并提交修改。只安装所选项目需要的工具；另一项目可以原样保留。
5. 对照所选项目的验收清单及[成果说明](common/deliverables.md)整理代码和文档。

## 选择项目

| | Python 工具服务 | Rust 通信服务 |
|---|---|---|
| 适合起点 | 刚学过变量、分支、循环、函数，想通过已有程序练习项目开发 | 能独立写简单输入处理输出程序，愿意学习 Rust |
| 起始内容 | 完整同步通信、ping/echo、服务端文本统计 | 同步客户端、同步服务端、异步服务端三个独立 Cargo 项目，均支持 ping |
| 主要任务 | 接入客户端、增加数值统计和内存键值存取 | 扩展协议、完善连接处理、实现并发、超时和退出 |
| 入口 | [Python 项目](projects/python/README.md) | [Rust 项目](projects/rust/README.md) |

尚未掌握基础语法者先补学再进入编程项目。不要求事先学过 Rust；路线不是能力等级，可以根据学习情况调整。

## 仓库地图

- `common/`：工程基础指引和成果要求。
- `projects/python/`：Python 源码、测试、协议及自查。
- `projects/rust/`：三个独立 Cargo 项目、协议及自查，不使用 workspace。
- `reference/`：[通用协议参考程序](reference/README.md)，用于替换通信一端验证行为。

项目使用同一通用消息约定，但只需完成所选项目的动作范围。参考程序覆盖全部动作，不代表你需要实现全部动作。基线测试默认全部通过；后续阶段自查需在完成对应功能后显式运行。
