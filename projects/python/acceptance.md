# Python 验收清单

先阅读[协议](protocol.md)。自查脚本仅覆盖少量正常输入；请为下面的边界自行设计测试，并保留原有 ping/echo 行为。

| 阶段 | 可观察要求 | 建议验证 |
|---|---|---|
| 基线 | 两端可运行，已有检查通过 | 启动服务端，菜单 ping/echo，运行默认测试 |
| 文本统计 | 客户端能输入、发送和显示服务端结果 | 空文本、中文、换行、尾换行；结果来自服务端 |
| 数值统计 | 输入解析、服务端校验、统计结果、错误显示 | 单数、负数、小数、重复值；空数组、布尔值、字符串和越界值 |
| 内存存取 | 写入、读取、覆盖、列举、删除及错误 | 空状态、缺失键、覆盖、容量边界、客户端重连、服务端重启 |
| 回归 | 新功能不破坏已有行为 | 一次连接发送合法、非法、合法请求；检查原有测试 |

请分别检查客户端正常操作入口和服务端协议行为。自查脚本直接发消息，因此不能证明菜单或输入处理正确。

对客户端，可使用参考服务端；对服务端，可使用参考客户端和[自查工具](self-check/README.md)。两端同时由自己编写时，仅能互通不足以证明协议正确。

按 README 执行类型、格式、静态检查和测试。
