# `client-sync`：同步客户端

这是候选人项目的第一层，也是必做层级。起始代码已经提供 HTTP 请求封装、JSON 响应解析、命令循环、注册、登录、退出和文本列表的基础流程。

## 需要完成的内容

- 补齐 `echo`、`delay`、注销账号、上传文本、获取文本和删除文本等操作。
- 处理登录令牌、401 响应、网络错误和退出行为。
- 支持 Unicode、空文本和多行文本，并清楚说明终端输入的结束方式。
- 让客户端遵守协议规定的 12 秒总操作期限。
- 为请求构造、响应处理和用户输入补充测试与说明。

客户端层级可以使用 Releases 中的完整 `rm-server-async` 参考程序进行验证。参考程序虽然由 Rust 构建，但通过统一 HTTP 协议服务 Python 客户端。

从本目录开始：

```text
uv sync --locked
uv run pytest
uv run rm-client --url http://127.0.0.1:7878
```

接口字段和状态码见[统一协议](../../../common/protocol.md)，最终检查见[统一验收清单](../../../common/acceptance.md)。
