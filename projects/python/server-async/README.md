# `server-async`：异步服务端

这是候选人项目的最终服务端层级，也是必做内容。起始代码使用 Starlette 和 Uvicorn，已经提供基础 HTTP 入口和部分同步业务逻辑；你需要把统一协议要求补完整。

## 需要完成的内容

- 完成与同步服务端相同的业务接口和输入边界。
- 使用异步等待实现 `delay`，不能阻塞其他请求。
- 正确管理并发注册、登录替换、文本修改和注销之间的共享状态。
- 将密码计算等阻塞工作移出事件循环，并避免在持有状态锁时等待网络或 delay。
- 在服务端任务后段加入令牌过期配置和检查。
- 实现请求读取期限、客户端可观察的错误处理和 Ctrl-C 后的有界退出。

可以使用自己的客户端，也可以使用 Releases 中的完整 `rm-client-sync` 参考程序进行验证：

```bash
uv sync --locked
uv run pytest
uv run rm-server --host 127.0.0.1 --port 7878
```

接口字段和状态码见[统一协议](../../../common/protocol.md)，最终检查见[统一验收清单](../../../common/acceptance.md)。
