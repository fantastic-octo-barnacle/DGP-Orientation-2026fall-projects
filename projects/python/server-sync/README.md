# `server-sync`：同步服务端

这是候选人项目的第二层，可选但推荐作为理解服务端的过渡。它按顺序处理请求，适合先学习路由、输入校验、身份验证和共享状态。

## 需要完成的内容

- 在起始代码基础上完成统一协议中的业务接口。
- 正确处理账号、令牌、文本隔离、错误状态码和输入边界。
- 在服务端任务后段加入令牌过期配置和检查。
- 编写单元测试、HTTP 测试和运行说明。

如果你已经能直接处理异步任务，可以跳过本目录，直接完成 `server-async`；跳过时仍需完成客户端和异步服务端。

可以使用自己的客户端，也可以使用 Releases 中的完整 `rm-client-sync` 参考程序进行验证：

```text
uv sync --locked
uv run pytest
uv run rm-server --host 127.0.0.1 --port 7878
```

接口字段和状态码见[统一协议](../../../common/protocol.md)，最终检查见[统一验收清单](../../../common/acceptance.md)。
